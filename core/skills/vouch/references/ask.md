# 脇質問

`/vouch ask <質問>`（Codex は `$vouch ask <質問>`）は、進行中の作業に影響を与えずに気になったことを聞く入口である。別コンテキストが読み取りだけで答え、状態を変えない。根拠は決定記録 §5。

## 記録

入力を受けた時点で UserPromptSubmit フックが、明示した Intent の監査に aside.asked（actor:human、質問の原文）を記録する。同じ回のターンが終わると Stop フックが aside.answered（親、所要時間、最後の返答）を記録する。モデルは記録を書き足さず、記録済みと報告するのはフックが記録した時だけである。Intent が未指定の時は記録されないことを伝える。[R-PROJECT-3]

## 答え方

`vouch-explorer` を別コンテキストで起動し、質問と対象 Intent のフォルダ、知識レイヤー（`vouch/knowledge/`）、必要なコードを読み取りだけで調べさせる。この起動では知識レイヤーの更新・再走査、成果物・コード・設定の変更、別のエージェントの起動、人への構造化質問をさせない。

返答は explorer の報告を基に、答え、参照元（パス:行@commit、文書#節@日付、URL＋節）、確かめていない範囲を短く返す。参照元のない主張をしない。知識が古いと分かれば、その事実と再走査が必要な範囲を示すだけにする。[R-PROJECT-2]

## 行わないこと

脇質問の中でステージ・Unit を進めない。DoD の実行、成果物の編集、確認・承認・判断依頼への回答や既定適用をしない。返答の後に元の作業へ戻るかどうかは利用者の次の入力に任せる。

同じ内容が以前に聞かれていれば、監査の aside.asked / aside.answered の ID と答えを示し、変わった前提だけを調べ直す。
