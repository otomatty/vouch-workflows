# Status のモデル評価素材

cases.json は手製の入力と評価観点です。synthetic:true、execution:not-run は、実機ハーネスのイベント採取やモデル評価の実績ではないことを示します。通常の CI は JSON の構造と正常例の監査スキーマだけを検査します。モデルの回答に合格を付けません。

評価時は隔離したプロジェクトへ生成済みの配布をコピーし、各ケースの files をそのプロジェクト内に展開します。ケースの prompt で status を呼び出し、別コンテキストで expect と実際の返答を比較します。Node 不在のケースは評価用プロセスの PATH だけで再現し、PC の設定を変えません。

評価結果にはハーネスとモデルの版、利用した Skill のコミット、入力ケース、実際の返答、引用したファイル・イベント、期待との相違、実行前後の全ファイル比較を残します。実行前のデータへ合否を書き足して評価済みとは扱いません。ネットワークやモデルを使う評価は通常の check から実行しません。
