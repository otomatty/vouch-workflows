# Intent 下書きのモデル評価素材

cases.json は手製の入力と評価観点で、synthetic:true / execution:not-run として保管します。実機イベント fixture やモデルの実行結果ではありません。通常の CI は入力データの構造だけを検査し、Skill の文章作成・ファイル保護・承認判断に合格を付けません。

評価時は各ケースを独立した一時プロジェクトへ展開し、生成済み配布をコピーして prompt を実行します。危険な出力先のケースは一時領域の中で親と兄弟ディレクトリも隔離します。Node 不在は評価プロセスの PATH だけで再現します。PC や実プロジェクトの設定を変更しません。

ハーネスとモデルの版、Skill のコミット、入力、実際の発言とツール操作、生成された全文、引用の出所、期待との差、前後の全ファイル差分を残します。起動フックによる変更と Skill 実行による変更を区別します。入力へ評価済みと書き込まず、結果は別に記録します。日英の品質、AC と検証の対応、選択肢の根拠、既存回答の保持、承認・監査の境界は別コンテキストで比較する項目です。
