# プロジェクトの規約

<!-- sec:configuration -->
## 設定

language と checkpoints は workflow.json の選択肢に合わせる。このファイルを採用する時にプロジェクト固有の欄を記入する。未記入は未設定であり、検証成功や承認を表さない。

<!-- sec:dependencies -->
## 依存ルール

利用する依存、追加・更新の根拠、ライセンスと脆弱性の確認方法を記入する。実行時と開発時の依存を区別する。依存監査のコマンドは DoD に置く。根拠は決定記録 §18 Q3。

<!-- sec:checkpoints -->
## 確認点

checkpoints の既定は topic。topic の論点と適用条件は workflow.json の topic_checkpoints に従う。H 階層では high_risk_adds の Unit 確認を追加する。unit / section に変更する時はその範囲を記入する。決定は decisions.md に人の言葉で残し、監査を手で補わない。[R-PROJECT-3]
